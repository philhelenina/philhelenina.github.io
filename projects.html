Emotion-Aware Conversational AI for Dementia Care

Role: AI/ML Lead Funding: UCOP Noyce Initiative ($300,000)

Overview

Leading the development of a clinically-validated AI pipeline for managing dementia-related agitation through therapeutic conversational interactions. This project creates the first AI system that combines real-time emotion recognition with expert-designed therapeutic response generation for the 55+ million people worldwide living with dementia.

Technical Contributions

  • Real-time Speech Emotion Recognition: Developed a wav2vec2-based emotion classifier achieving ~80% accuracy on detecting agitation, frustration, and engagement states from raw audio.
  • Therapeutic Response Generation: Engineered LLM prompting strategies (GPT-3.5/4) with clinician-validated therapeutic redirection techniques, including memory-based engagement and de-escalation protocols.
  • Voice Synthesis for Elderly Care: Implemented prosodic modifications using Azure Cognitive Services to generate age-appropriate, calming voice outputs with controlled pitch and speech rate.
  • Semantic Similarity Evaluation: Built conversation quality metrics using SentenceTransformers for comparing generated responses against clinical gold standards.

Linguistics & Cognitive Science Integration

  • Designed expert personas (Rachel, Jolene, Ralph) modeling different dementia severity levels based on clinical discourse patterns
  • Implemented episodic memory triggers leveraging autobiographical memory research
  • Applied therapeutic communication frameworks from dementia care literature
Technologies: Python, PyTorch, Transformers, OpenAI Whisper, wav2vec2, Azure Cognitive Services, Streamlit, HuggingFace, SentenceTransformers
Press Coverage Published Protocol (JMIR)

SenticCrystal: Information-Theoretic Emotion Recognition

Role: Principal Investigator NVIDIA Academic Grant Recipient

Overview

Developing an interpretable framework for multimodal emotion recognition that prioritizes simplicity and transparency over black-box complexity. The core philosophy is "crystallizing" essential emotional principles from data using information-theoretic diagnostics.

Technical Contributions

  • Competitive Text-Only Performance: Achieved 73.25% accuracy on IEMOCAP 4-way emotion classification using interpretable features, competitive with transformer-based approaches.
  • Class Imbalance Solution: Recovered from catastrophic model failure (30.9% → 69.94%) through Focal Loss optimization (α=1.0, γ=1.2), eliminating 10-80% class bias.
  • Hybrid Feature Architecture: Combined WordNet-Affect semantic embeddings with contextual RoBERTa representations for emotionally-grounded text understanding.
  • Information-Theoretic Diagnostics: Implemented Shannon entropy and mutual information analysis for model interpretability and feature selection.

Linguistics & Cognitive Science Integration

  • Leveraged psycholinguistic resources (WordNet-Affect) encoding semantic relationships of emotion terms
  • Analyzed context dependency in emotional expression across conversational turns
  • Focused on interpretability: understanding why models make emotion predictions
Technologies: Python, PyTorch, CUDA, Transformers, RoBERTa, LSTM, Scikit-learn, HuggingFace Accelerate, Information Theory libraries
IEMOCAP Dataset (USC SAIL)

Vision-Based Movement Transition Detection for Fall Prevention

Role: Co-Investigator Submitted to Smart Health 2025

Overview

Developing a framework that uses temporal logic and finite state machines to detect transition triggers in human movement sequences. The system identifies when an older adult intends to transition between physical states (sitting-to-standing, walking-to-sitting) before the movement occurs, enabling proactive fall prevention.

Technical Contributions

  • Real-Time Pose Detection: Integrated MoveNet Lightning for 17-keypoint human skeleton extraction at real-time speeds on edge devices (NVIDIA Orin).
  • Formal State Machine Encoding: Designed finite state machines capturing valid movement transition sequences with temporal logic rules.
  • Predictive Intention Detection: Implemented algorithms detecting pre-movement states (intention to move) before actual movement onset.
  • Hip-Centered Normalization: Developed pose normalization: pose_size = max(2.5 × torso_size, max_i ||k_i - c_hip||) for scale-invariant analysis.

Cognitive Science Integration

  • Models biomechanics of human movement transitions based on rehabilitation science literature
  • Detects cognitive/motor intention signals preceding physical movement
  • Addresses fall risk in elderly populations through predictive (not reactive) intervention
Technologies: Python, TensorFlow, MoveNet, OpenCV, Finite State Machines, Temporal Logic, NVIDIA Orin (Edge Deployment)
